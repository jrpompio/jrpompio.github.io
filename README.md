# Personal portfolio

Static personal portfolio published with GitHub Pages at https://jrpompio.github.io/.

This repository contains only the public portfolio page. Private CV source files and project notes remain in the separate private repository.

In the **Software** discipline, the illustration is a small browser game: click or tap it, or focus it and press Enter/Space, to flap the red ball through the gaps. After a collision, activate it again to restart. The game also supports reduced-motion settings with step-by-step controls.
